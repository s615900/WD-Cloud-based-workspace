## 0. 功能範圍

- 側邊欄新增「人事 → 人事假勤」（`/desktop/hr`），三個分頁：員工名冊／請假紀錄／法規對照
- 員工：新增、編輯、離職（保留資料）、刪除（連同請假紀錄一起刪）
- 請假：12 種假別，以「天（8 小時）」或「小時」登記（最小單位 0.5 小時），刪除
- 自動計算（`src/lib/leave.ts`，有單元測試 `src/lib/leave.test.ts`）：
  - 特休：勞基法第 38 條、週年制，顯示本週期應給／已休／剩餘、週期起訖，週期結束前 60 天提醒未休日數
  - 事假：曆年 14 日（家庭照顧假併入，另顯示 56 小時上限）
  - 普通傷病假：曆年 30 日，10 日內標示「不得不利處分」（115/1/1 新制）；生理假超過全年 3 日的部分併入
  - 其他假別：依法定日數提示
- 新增請假時即時提示剩餘額度、超過上限時以金色字警告（不擋，因為公司可給優於法令的假）
- 登入保護：`/api/hr/*` 已加入 `src/proxy.ts` matcher，跟其他模組一樣只有 ALLOWED_LINE_USER_ID 能用

## 1. Ragic 建表（WD 手動）

在 qsprint 帳號底下新增一個頁籤（建議命名「人事」），建立兩張表。**欄位名稱要一字不差**，程式讀取（GET）就是用這些中文名稱當 key。

### 1-1 員工資料

| 欄位名稱 | Ragic 欄位型態 | 選項／備註 |
| --- | --- | --- |
| 員工編號 | 文字 | 選填，例：E001 |
| 姓名 | 文字 | 必填（程式端驗證） |
| 部門 | 文字 | |
| 職稱 | 文字 | |
| 到職日 | 日期 | yyyy/MM/dd，必填（程式端驗證） |
| 性別 | 單選 | 女／男／其他 |
| 電話 | 文字 | 用文字，不要用電話型態（避免格式被改） |
| Email | 文字 或 Email | |
| 在職狀態 | 單選 | 在職／離職，預設值設「在職」 |
| 離職日 | 日期 | yyyy/MM/dd |
| 備註 | 段落文字 | |

### 1-2 請假紀錄

| 欄位名稱 | Ragic 欄位型態 | 選項／備註 |
| --- | --- | --- |
| 員工紀錄編號 | 文字 | 存「員工資料」那筆的 Ragic 內部紀錄編號（純數字字串）。**不要用連結欄位**，連結欄位寫入規則不同 |
| 員工姓名 | 文字 | 只是方便在 Ragic 後台看，程式不依賴 |
| 假別 | 單選 | 特休／事假／家庭照顧假／普通傷病假／生理假／婚假／喪假／公傷病假／公假／產假／產檢假／陪產檢及陪產假（12 個，順序不拘，文字要一模一樣） |
| 請假日期 | 日期 | yyyy/MM/dd |
| 時數 | 數字 | 允許小數（0.5） |
| 備註 | 文字 | |

> 假別選項少打或打錯字，Ragic 會 HTTP 200 但把欄位存成空白——跟報價單稅率 `"5%"` 是同一種靜默失敗。

## 2. 欄位盤點並填入 `hrRagic.ts`（Claude Code）

**主積木：** `src/server/lib/hrRagic.ts`（只改這一支）

1. 用 Ragic MCP `list_sheets(apname: "qsprint")` 或兩次 GET（`?api&v=3&limit=1` 取中文 key、`?api&v=3&info=true` 取欄位編號）取得兩張表的：
   - 表單路徑（例：`hr/1`、`hr/2`）→ 填 `HR_SHEET.employees`、`HR_SHEET.leaves`
   - 每個欄位的編號 → 填 `EMPLOYEE_FIELD`、`LEAVE_FIELD`
2. 核對 `EMPLOYEE_READ_FIELD`、`LEAVE_READ_FIELD` 的中文名稱跟 Ragic GET 回應的 key 完全一致（全形／半形括號、空白都要比對）
3. 確認沒有任何空字串殘留（`hrConfigured()` 會檢查，有一個空的整個模組就維持 503）

**不准動：** `quotationRagic.ts`、`ragic/client.ts`、`bot/ragic.ts`、其他模組的 API 與頁面、`businessLock.ts`

## 3. 驗收（實機／瀏覽器，不接受只跑 tsc）

在正式網址 `/desktop/hr`（或 `npm run dev` + 真實 Ragic）逐項操作，**每項都要到 Ragic 後台確認資料真的寫進去**：

1. [ ] 新增員工（姓名、到職日 2023-03-15、在職）→ Ragic「員工資料」出現一筆，到職日是 2023/03/15、在職狀態「在職」
2. [ ] 名冊顯示年資「3 年 x 個月」、特休 14 日（以 2026/10 為準）
3. [ ] 對該員工新增「特休 2 天」→ Ragic「請假紀錄」出現一筆：員工紀錄編號＝員工那筆的紀錄編號、假別「特休」、時數 16
4. [ ] 名冊特休剩餘變成 12；假勤卡顯示週期 2026-03-15 ～ 2027-03-14、已休 2 日
5. [ ] 新增「家庭照顧假 3 小時」→ 年度事假顯示 0.38、假勤卡顯示「含家庭照顧假 3 小時」
6. [ ] 編輯員工改成離職 → Ragic 在職狀態「離職」、離職日有值；名冊預設篩選（在職）看不到他，切「全部」看得到
7. [ ] 請假紀錄分頁刪除一筆 → Ragic 該筆消失
8. [ ] 刪除員工 → 該員工與他所有請假紀錄都從 Ragic 消失（確認 `where=<員工紀錄編號欄位>,eq,<id>` 篩選有效，**沒有誤刪別人的紀錄**）
9. [ ] 登出後直接打 `GET /api/hr/employees` → 401
10. [ ] iPhone Safari（390 寬）名冊為卡片、無橫向捲軸
11. [ ] `npm test` 全數通過

第 8 項是唯一有連帶刪除的操作，務必先建一位測試員工＋另一位員工的請假紀錄再測。
