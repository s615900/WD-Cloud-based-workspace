# 10｜預排班（排班算工時與薪資）：Ragic 建表

> 頁面：`/desktop/plan`（側邊欄「人事 → 預排班」）。程式已完成，**Ragic 兩件事做完、欄位編號填好之後才能存資料**。

## 功能

- 班別模板跟行事曆**共用同一張表**（`ragicforms21/6`），在預排班頁新增的模板，行事曆也看得到，反之亦然
- 點模板再點日期排班；「整月重複排班」選星期一次排整個月
- 每筆班可單獨改時間、休息、時薪（只改那一天，不動模板）
- 自動算每天工時、當月各班別次數／工時／薪資、合計與逐筆明細
- 預排班存在獨立的表，**不會**出現在行事曆、LINE 每日提醒，也不影響空檔推算
- 薪資 = （結束 − 開始 − 不計薪休息）÷ 60 × 時薪；結束早於開始視為跨日；每筆四捨五入到整數元，月薪資是逐筆加總

## 1. Ragic：班別模板表（`ragicforms21/6`）多加 2 欄

| 欄位名稱 | 型態 | 備註 |
| --- | --- | --- |
| 時薪 | 數字 | 這個班別的時薪 |
| 休息分鐘 | 數字 | 不計薪的休息時間（分鐘） |

## 2. Ragic：新建「預排班」表（建議放同一個資料夾 `ragicforms21`）

**欄位名稱要一字不差**（讀取用中文名稱當 key）。

| 欄位名稱 | 型態 | 備註 |
| --- | --- | --- |
| 日期 | 日期 | |
| 班別編號 | 文字 | 對應班別模板的「模板編號」，自訂班可空白 |
| 班別名稱 | 文字 | |
| 開始時間 | 文字 | HH:mm（跟班別模板一樣用文字欄位） |
| 結束時間 | 文字 | HH:mm |
| 休息分鐘 | 數字 | |
| 時薪 | 數字 | |
| 備註 | 文字 | |

## 3. 填欄位編號（Claude Code）

1. 用 Ragic MCP 或 `?api&v=3&info=true` 查出新表的路徑（預設猜 `/12`）與每個欄位的編號
2. 改 `src/server/ragic/fields.ts`：
   - `SHEET.plan` 填新表路徑
   - `F_PLAN` 的 8 個欄位編號（0 = 未設定；有任何一個是 0，API 回 503、頁面顯示設定說明）
   - `F_TEMPLATE.rate`、`F_TEMPLATE.breakMin` 填模板表新增的兩欄編號
3. 驗收：預排班頁排一個班 → Ragic 預排班表出現一筆（日期、開始結束、休息、時薪都有值）；編輯後 Ragic 同步更新；刪除後消失；行事曆頁**沒有**多出任何行程

> 沒填 `F_TEMPLATE.rate／breakMin` 時：模板的時薪不會被存、也讀不到，預排班頁會顯示黃色提醒。
